# Approved Style and Not Acceptable

## Approved (match these)
1. **"AI COSTS" stat frame.** Heavy condensed uppercase headline, one orange keyword, a simple bar, lots of whitespace.
2. **"Polite salesperson" phone frame.** Real-looking chat phone with a clean caption card in the same condensed headline plus a clean body sans.
3. **Logo reveal ("MEET ForgeHype").** Wide wordmark, orange Forge, light Hype, on dark.
4. **3-device mockup** (driver, customer, admin screens) on dark.
5. **Fixed-frame approach in "Photo proof."** Layout, phone and components stay fixed; only the state changes (take photo to photo saved). Keep this approach. Its separation on the light background was weak and is corrected in design-rulebook.md.

## Not acceptable (never produce)
| Problem | Rule |
|---|---|
| Text cut off at the edges | Auto-fit inside the content box; QA fails on overflow |
| Content ignores platform blind zones | Per-platform safe areas, build to the stricter one |
| Logo retyped or mismatched | Official logo files only |
| Off-brand colors (blue, purple, green, red icons, WhatsApp green button) | Accent orange plus neutrals only; third-party logos only in a neutral container |
| Very wide display font | Heavy condensed headline font |
| Too fast, no breathing time | 5-6 second scenes, one fixed layout |
| Many different sounds, pops and clicks | At most one soft sound per scene change |
| Elements flying in from all directions | One motion language: fade with a small rise |
| CapCut watermark and black bars | Render directly from Remotion at exact canvas size |
