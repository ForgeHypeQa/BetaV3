# Scene Library

Prebuilt components. Each follows the standard layout in design-rulebook.md. Props: mode, label, headline, keyword, visual (state), caption.

| Component | Use | Swappable part |
|---|---|---|
| Statement | One strong message with an icon | keyword or icon |
| ChatPhone | Customer conversation, response quality | chat message |
| DeviceMockup | One product screen | UI state (for example, photo taken to saved) |
| MultiDevice | Product reveal with 3 screens | which screen is highlighted |
| ListCard | Several items or updates | item states |
| StatBar | Cost or measured claims | bar value |
| BigNumber | Price or count | number |
| LogoReveal | Opening or "Meet X" | none |
| EndCard | Logo and CTA | none |

Optional storytelling props from earlier ForgeHype frames (sign, bell, lamp, door) are allowed in dark scenes if the owner approves them.

Adding a component: Claude proposes it with a text description, the owner approves, it is built once, added here and logged.
